# 装具びより — 下肢装具サポートPWA

短下肢装具の耐用年数は、構造や利用する制度によって異なります。公的な基準では、金属支柱付きは3年、支柱のない硬性装具は1.5年、軟性装具は2年などの目安があります。

これらは、年数が来ると必ず使えなくなるという意味ではありません。装具の破損や身体への適合状態、修理の可否などによって、修理や作り替えを検討します。実際の取り扱いは、利用する制度や専門職にご確認ください。

**「装具びより」は、下肢装具を使っている方が、ご自身の装具や日々の記録、相談したいことを整理するためのアプリです。**

装具を使って感じたことを少しずつ記録し、医師、義肢装具士、理学療法士などに相談するときに、伝えたい内容をまとめた「相談シート」を作成できます。

また、「どこへ行けば相談やアドバイスを受けられるのか分からない」という方のために、住所と探したい目的を入力して、リハビリ施設や義肢装具店などを地図で探せる機能も用意しています。

記録した内容が、医療機関や専門職などへ自動で送信されることはありません。必要なときに画面を見せたり、相談シートを印刷したりしてご利用ください。
